# pr-pertama

Repo latihan untuk belajar alur Pull Request di GitHub.

## Isi

- `kalkulator.py` — fungsi sederhana `tambah` dan `kurang`.
- `test_kalkulator.py` — test unit memakai `unittest` bawaan Python.

## Menjalankan test

```bash
python3 -m unittest -v
```

Semua test seharusnya lulus sebelum perubahan di-merge ke `main`.
Silakan buka PR untuk perbaikan kecil seperti typo atau tes yang kurang.
